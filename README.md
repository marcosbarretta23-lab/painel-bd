# painel-bd

Páginas estáticas do painel de pedidos da rede Black Dog.

São só HTML: os dados vêm de uma API que exige senha, e nada aqui dá acesso a nada.
Cada página pede a senha do seu grupo de lojas e guarda no próprio navegador.

`apuracao.html` é outra coisa: a apuração do 2º turno de 2026 (25/10), lida direto dos arquivos
públicos do TSE pelo navegador. Não usa senha nem dado da rede.
